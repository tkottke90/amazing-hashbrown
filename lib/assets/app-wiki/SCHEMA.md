# App Documentation Wiki — Schema

## Domain

application configuration, features, providers, wiki, and how-to guides

## Purpose

This wiki contains user-facing documentation for the application, generated from
the curated source docs in `docs/app-wiki/` during the release process. Content
must be understandable without reading source code — no API internals, no
developer-facing architecture.

## Page Types

- **concept** — how a feature works (e.g. "How the Wiki Works", "AfterAgent Pipeline")
- **entity** — a specific configurable thing (e.g. "Ollama Provider", "MCP Server")
- **query** — captured how-to Q&A (e.g. "How do I configure MCP?")
